# موقع مساحات — نسخة واحدة (One-Page)

## البنية
```
masahat-site/
├── index.html              ← الموقع كامل (HTML + CSS + JS + إعدادات الصور بملف واحد)
├── images/
│   ├── shoot-edit.jpg      ← صورة تصوير/مونتاج
│   ├── land-plan.jpg       ← مخطط/كروكي أرض
│   ├── handover.jpg        ← تسليم مفاتيح عقار
│   └── README.txt          ← أي صورة تُستخدم بأي شريحة
├── videos/
│   └── masahat-hero.mp4    ← فيديو خلفية الصفحة الرئيسية (أضفه بنفسك)
└── README.md
```

## الصور
كل الشرائح (ما عدا الرئيسية التي تستخدم فيديو) لها خلفية صورة مموّهة، من
الصور الثلاث في مجلد images/. لتغييرها: افتح index.html وابحث عن
"SITE_BACKGROUNDS" قرب نهاية الملف، وبدّل قيمة "image" لأي قسم.

## الرفع على GitHub (Pages)
1. أنشئ مستودع (Repository) جديد في GitHub
2. ارفع محتويات هذا المجلد بالكامل كما هي (بنفس بنية المجلدات — index.html
   و images/ و videos/ في نفس المستوى)
3. من إعدادات المستودع: Settings → Pages → اختر الفرع الرئيسي (main) والمجلد
   الجذر (/root)
4. بعد دقيقة أو دقيقتين، الموقع يكون شغّال على:
   `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

## ملاحظة مهمة عن الفيديو
مجلد videos/ فاضي حاليًا — لازم تضيف ملف masahat-hero.mp4 بنفسك (لقطات جوية
أو مشهد يمثل مساحات)، وإلا الصفحة الرئيسية تعرض تدرّج تيل بديل بدل الفيديو
تلقائيًا (fallback مدمج، الموقع ما ينكسر بدون الفيديو).
